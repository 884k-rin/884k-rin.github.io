OpenClaw プライバシーポリシー

このポリシーは、884k-rin が個人利用する OpenClaw / gog CLI 用 Google OAuth アプリに適用されます。

アクセスする情報と目的

本アプリは、本人が Google の同意画面で明示的に許可した範囲のアカウント情報および Google サービスのデータにアクセスし、本人が指示する取得・検索・作成・更新などの操作に使用します。対象には、利用する機能に応じてメール、予定、ファイル等が含まれる場合があります。実際に許可するデータと操作は、認可時の同意画面に表示されます。

処理・保存

認可トークンは gog CLI の認証設定に従って利用環境で管理されます。取得したデータ、実行結果、キャッシュおよびログの保存場所と期間は、gog CLI、OpenClaw および利用環境の設定によります。この GitHub Pages の説明用ウェブサイトでは Google ログインを実装せず、Google データや認可トークンを受信・保存しません。

外部との連携

Google API の呼び出しでは、認証情報および操作に必要な情報が Google に送信されます。OpenClaw で外部 AI サービスやその他の連携を有効にした場合、利用者の指示と設定に応じて、取得した情報がその連携先に送信される場合があります。利用者は、連携先の設定とプライバシーポリシーを確認し、不要な情報を送信しないよう管理してください。Google ユーザーデータを販売せず、広告配信のためには使用しません。

Google API のデータ利用

Google API から取得する情報の使用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use 要件を含む）に従うものとします。

アクセスの取り消し・データの削除

利用者は Google アカウントの接続管理 で本アプリへのアクセスを取り消せます。保存済みのトークン、取得データやログは、使用した CLI、OpenClaw、端末および外部連携先の管理機能で別途削除してください。アクセスの取り消しだけでは保存済みデータは削除されません。

このウェブサイト

説明用ページは GitHub Pages で配信しています。配信に伴うアクセス情報の取り扱いは GitHub のプライバシーに関する声明 に従います。本ページ独自のアクセス解析や入力フォームは設置していません。
